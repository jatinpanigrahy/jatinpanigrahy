### 💻 My Projects

- **[url-shortener-app](https://github.com/jatinpanigrahy/url-shortener-app)**
  A lightweight, full-stack URL shortening application built with Python, Flask and SQLite. Features collision-resistant Base62 link generation, customizable link expiration, sliding-window rate limiting, and role-based administrative moderation.

- **[csv-sanitizer](https://github.com/jatinpanigrahy/csv-sanitizer)**
  CSV Sanitizer is a configurable Python tool designed to clean messy data in CSV files. It standardizes different formats across common business fields, detects duplicate rows using fuzzy matching, and generates a clear Markdown report summarizing every change made.

- **[content-analyzer](https://github.com/jatinpanigrahy/content-analyzer)**
  A fast, responsive web application to analyze digital content using large language models. It extracts text from web pages, processes it into structured insights across eight specialized analysis modes, and generates export-ready Markdown and PDF reports.

- **[github-dev-analytics](https://github.com/jatinpanigrahy/github-dev-analytics)**
  A fast, interactive dashboard to visualize GitHub profiles and repository data in real-time. Built with Python and Streamlit, featuring automated caching and a clean, responsive design.

  An interactive personal budget tracker and spending dashboard. Built with Python and Streamlit, featuring category-based budgeting, real-time analytics, and portable JSON data persistence.
